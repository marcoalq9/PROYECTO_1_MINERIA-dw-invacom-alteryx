# Medidas DAX de K7 y K8

> Jira: DWI-88 · Responsable: Marco Andrey López Quesada
> KPIs aprobados en `docs/entrega/metodologia-kpis.md`.

| KPI | Pregunta | Meta | Sentido favorable |
|---|---|---|---|
| K7 · Tasa de devoluciones fuera de plazo | ¿Qué porcentaje de los alquileres devueltos llegó tarde? | ≤ 45 % | Bajar |
| K8 · Días promedio de atraso | Cuando una devolución llega tarde, ¿por cuántos días? | ≤ 2,0 días | Bajar |

Los dos se calculan sobre `fact_alquiler`, por tienda y por **mes de inicio del alquiler** (`dim_fecha`).

## Antes de crearlas

Las medidas usan dos relaciones que ya existen en `Dashboard_Invacom.pbix`:

- `fact_alquiler[fecha_key]` → `dim_fecha[fecha_key]` (muchos a uno).
- `fact_alquiler[tienda_key]` → `dim_tienda[tienda_key]` (muchos a uno).

Las medidas del mes anterior incluyen `REMOVEFILTERS ( dim_fecha )`, así que funcionan aunque `dim_fecha` todavía no esté marcada como tabla de fechas. Marcarla en DWI-81 sigue siendo recomendable.

Se crean en la tabla `fact_alquiler` (*Inicio → Nueva medida*), con el formato indicado en cada una.

## K7 · Tasa de devoluciones fuera de plazo

**Valor.** Formato: porcentaje, 1 decimal.

```dax
K7 Devoluciones tardías % =
VAR Tardias = SUM ( fact_alquiler[devolucion_tardia] )
VAR Evaluables =
    CALCULATE (
        COUNTROWS ( fact_alquiler ),
        NOT ISBLANK ( fact_alquiler[devolucion_tardia] )
    )
RETURN
    DIVIDE ( Tardias, Evaluables )
```

`devolucion_tardia` es 1 si se devolvió tarde, 0 si a tiempo y nulo si no se devolvió. El denominador cuenta solo las filas con valor, es decir, los alquileres devueltos con un plazo válido. Es la comprobación de nulos que pide la ficha del KPI: si todos los devueltos tienen plazo válido, da lo mismo que `SUM(devuelto)`. `DIVIDE` devuelve vacío cuando no hay devoluciones, en lugar de un error.

**Meta.**

```dax
K7 Meta = 0.45
```

**Mes anterior.** Formato: porcentaje, 1 decimal.

```dax
K7 Mes anterior =
CALCULATE (
    [K7 Devoluciones tardías %],
    PREVIOUSMONTH ( dim_fecha[fecha] ),
    REMOVEFILTERS ( dim_fecha )
)
```

`PREVIOUSMONTH` toma las fechas del mes anterior al que se está viendo. `REMOVEFILTERS` quita el filtro de año y mes del visual; sin él, Power BI buscaría el mes anterior dentro del mes actual y daría vacío.

**Variación en puntos porcentuales.** Formato: número, 1 decimal.

```dax
K7 Variación (pp) =
VAR Actual = [K7 Devoluciones tardías %]
VAR Anterior = [K7 Mes anterior]
RETURN
    IF (
        ISBLANK ( Actual ) || ISBLANK ( Anterior ),
        BLANK (),
        ( Actual - Anterior ) * 100
    )
```

Si sube de 50,0 % a 52,5 %, la variación es +2,5 pp. Para K7 una variación negativa es buena.

**Texto para tarjetas.** Muestra «Sin dato» en lugar de *(En blanco)*.

```dax
K7 Texto =
VAR Valor = [K7 Devoluciones tardías %]
RETURN
    IF ( ISBLANK ( Valor ), "Sin dato", FORMAT ( Valor, "0.0 %" ) )
```

**Estado y color** (para el formato condicional, *Valor del campo*).

```dax
K7 Estado =
VAR Valor = [K7 Devoluciones tardías %]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( Valor ), "Sin dato",
        Valor <= [K7 Meta], "Cumple la meta",
        "No cumple la meta"
    )

K7 Color =
VAR Valor = [K7 Devoluciones tardías %]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( Valor ), "#737373",
        Valor <= [K7 Meta], "#5BD667",
        "#FF6B76"
    )

K7 Color variación =
VAR Variacion = [K7 Variación (pp)]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( Variacion ), "#737373",
        Variacion < 0, "#5BD667",
        Variacion > 0, "#FF6B76",
        "#E6C84F"
    )
```

Los colores son los de `good`, `bad`, `neutral` y gris del tema `tema_invacom_elegido.json`.

## K8 · Días promedio de atraso

**Valor.** Formato: número, 1 decimal.

```dax
K8 Días promedio de atraso =
CALCULATE (
    AVERAGE ( fact_alquiler[dias_atraso] ),
    fact_alquiler[devolucion_tardia] = 1
)
```

Promedia `dias_atraso` solo entre las devoluciones tardías. Si en el mes no hay ninguna, queda vacío.

**Meta.**

```dax
K8 Meta = 2.0
```

**Mes anterior y variación en días.** Formato: número, 1 decimal.

```dax
K8 Mes anterior =
CALCULATE (
    [K8 Días promedio de atraso],
    PREVIOUSMONTH ( dim_fecha[fecha] ),
    REMOVEFILTERS ( dim_fecha )
)

K8 Variación (días) =
VAR Actual = [K8 Días promedio de atraso]
VAR Anterior = [K8 Mes anterior]
RETURN
    IF ( ISBLANK ( Actual ) || ISBLANK ( Anterior ), BLANK (), Actual - Anterior )
```

**Texto, estado y color.**

```dax
K8 Texto =
VAR Valor = [K8 Días promedio de atraso]
RETURN
    IF ( ISBLANK ( Valor ), "Sin dato", FORMAT ( Valor, "0.0" ) & " días" )

K8 Estado =
VAR Valor = [K8 Días promedio de atraso]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( Valor ), "Sin dato",
        Valor <= [K8 Meta], "Cumple la meta",
        "No cumple la meta"
    )

K8 Color =
VAR Valor = [K8 Días promedio de atraso]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( Valor ), "#737373",
        Valor <= [K8 Meta], "#5BD667",
        "#FF6B76"
    )

K8 Color variación =
VAR Variacion = [K8 Variación (días)]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( Variacion ), "#737373",
        Variacion < 0, "#5BD667",
        Variacion > 0, "#FF6B76",
        "#E6C84F"
    )
```

## Casos especiales

| Caso | Qué muestra | Por qué |
|---|---|---|
| Febrero de 2017 | K7 y K8 «Sin dato» | Los 182 alquileres de ese día no se devolvieron (C06, C07) |
| Variación de febrero de 2017 | «Sin dato» | Febrero no tiene devoluciones y enero de 2017 no tiene alquileres |
| Mayo de 2005 | Valor normal, pero es un mes parcial | Los datos empiezan el 24/05/2005 |
| Variación de mayo de 2005 | «Sin dato» | No hay datos de abril de 2005 |

## Comprobación contra SQL

La ficha del KPI pide comparar la medida con SQL sobre el DW. `sql/07_validacion_k7_k8.sql` calcula los mismos valores por tienda y mes. Para comprobar:

1. Ejecutar el script en SSMS.
2. En Power BI, poner una tabla con `dim_tienda[store_id]`, `dim_fecha[anio]`, `dim_fecha[mes]`, `K7 Devoluciones tardías %` y `K8 Días promedio de atraso`.
3. Los valores deben coincidir fila por fila con la tabla siguiente.

## Funciones DAX usadas

`SUM`, `COUNTROWS`, `AVERAGE`, `CALCULATE`, `DIVIDE`, `PREVIOUSMONTH`, `REMOVEFILTERS`, `ISBLANK`, `IF`, `SWITCH`, `FORMAT` y variables (`VAR … RETURN`). Sirven para la matriz de control de DWI-89.
