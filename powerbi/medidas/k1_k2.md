# Medidas DAX de K1 y K2

> Jira: DWI-85 · Responsable: Kristel Ramírez
> KPIs aprobados en `docs/entrega/metodologia-kpis.md`. 
Se construyen sobre las medidas base de `base.md` (DWI-84).

| KPI | Pregunta | Meta | Sentido favorable |
|---|---|---|---|
| K1 · Crecimiento mensual de ingresos | ¿Cuánto crecieron los ingresos frente al mes anterior? | ≥ +5 % | Subir |
| K2 · Ticket promedio por alquiler | ¿Cuánto deja en promedio cada alquiler? | ≥ 4,25 | Subir |

Los dos se calculan sobre `fact_alquiler`, por tienda y por **mes de inicio del alquiler** (`dim_fecha`), y ya están creados en `Dashboard_Invacom.pbix`, en las carpetas *K1 Crecimiento mensual de ingresos* y *K2 Ticket promedio por alquiler* de `fact_alquiler`. El valor principal de cada KPI tiene una descripción con su fórmula y su meta.

## K1 · Crecimiento mensual de ingresos

**Valor.** Formato: porcentaje con signo, 1 decimal.

```dax
K1 Crecimiento de ingresos % =
VAR UnMes =
    HASONEVALUE ( dim_fecha[anio] ) && HASONEVALUE ( dim_fecha[mes] )
VAR Actual = [Ingresos]
VAR Anterior = [Ingresos mes anterior]
RETURN
    IF (
        NOT UnMes || ISBLANK ( Anterior ) || Anterior = 0,
        BLANK (),
        DIVIDE ( Actual - Anterior, Anterior )
    )
```

Es la fórmula de la ficha: (ingreso del mes − ingreso anterior) ÷ ingreso anterior. Si el mes anterior no tiene ingresos o no existe, queda vacío y las medidas de texto muestran «Sin dato», como pide la ficha. `Ingresos mes anterior` ya resuelve el `PREVIOUSMONTH` (ver `base.md`).

`UnMes` revisa que el contexto tenga **un solo mes** (un año y un mes). K1 es un crecimiento mes contra mes, como dice la ficha: con varios meses, un año completo o sin filtro de fecha no hay un único mes anterior, y sumar varios meses daría un porcentaje sin sentido (por ejemplo, junio + agosto contra mayo daría +578,4 %). En esos casos la medida queda vacía y `K1 Texto` muestra «Elige un mes». En la página del tablero el segmentador de mes es de selección única.

**Meta.**

```dax
K1 Meta = 0.05
```

**Mes anterior y variación en puntos porcentuales.** Mismo patrón que K7.

```dax
K1 Mes anterior =
IF (
    ISEMPTY ( fact_alquiler ),
    BLANK (),
    CALCULATE (
        [K1 Crecimiento de ingresos %],
        PREVIOUSMONTH ( dim_fecha[fecha] ),
        REMOVEFILTERS ( dim_fecha )
    )
)

K1 Variación (pp) =
VAR Actual = [K1 Crecimiento de ingresos %]
VAR Anterior = [K1 Mes anterior]
RETURN
    IF ( ISBLANK ( Actual ) || ISBLANK ( Anterior ), BLANK (), ( Actual - Anterior ) * 100 )
```

**Texto, estado y color.** Para K1 lo favorable es subir: cumple si el valor es **mayor o igual** a la meta, y una variación positiva va en verde.

```dax
K1 Texto =
VAR UnMes =
    HASONEVALUE ( dim_fecha[anio] ) && HASONEVALUE ( dim_fecha[mes] )
VAR Valor = [K1 Crecimiento de ingresos %]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        NOT UnMes, "Elige un mes",
        ISBLANK ( Valor ), "Sin dato",
        FORMAT ( Valor, "+0.0 %;-0.0 %;0.0 %" )
    )

K1 Estado =
VAR UnMes =
    HASONEVALUE ( dim_fecha[anio] ) && HASONEVALUE ( dim_fecha[mes] )
VAR Valor = [K1 Crecimiento de ingresos %]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        NOT UnMes, "Elige un mes",
        ISBLANK ( Valor ), "Sin dato",
        Valor >= [K1 Meta], "Cumple la meta",
        "No cumple la meta"
    )

K1 Color =
VAR Valor = [K1 Crecimiento de ingresos %]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        ISBLANK ( Valor ), "#737373",
        Valor >= [K1 Meta], "#5BD667",
        "#FF6B76"
    )

K1 Color variación =
VAR Variacion = [K1 Variación (pp)]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        ISBLANK ( Variacion ), "#737373",
        Variacion > 0, "#5BD667",
        Variacion < 0, "#FF6B76",
        "#E6C84F"
    )
```

**Subtítulo de la tarjeta.** El porcentaje solo no dice qué se compara. `K1 Nota` arma el texto del subtítulo de la tarjeta (*Formato → General → Título → Subtítulo → fx → Valor del campo*) con los dos meses comparados, sus ingresos y la meta. También cumple lo que pide la ficha: identificar la comparación de junio con mayo de 2005, porque mayo es parcial.

```dax
K1 Nota =
VAR UnMes =
    HASONEVALUE ( dim_fecha[anio] ) && HASONEVALUE ( dim_fecha[mes] )
VAR Anio = SELECTEDVALUE ( dim_fecha[anio] )
VAR Mes = SELECTEDVALUE ( dim_fecha[mes] )
VAR MesActual = SELECTEDVALUE ( dim_fecha[nombre_mes] ) & " " & Anio
VAR FechaAnterior =
    CALCULATE ( MAX ( dim_fecha[fecha] ), PREVIOUSMONTH ( dim_fecha[fecha] ), REMOVEFILTERS ( dim_fecha ) )
VAR MesAnterior =
    CALCULATE ( SELECTEDVALUE ( dim_fecha[nombre_mes] ), PREVIOUSMONTH ( dim_fecha[fecha] ), REMOVEFILTERS ( dim_fecha ) )
        & " " & YEAR ( FechaAnterior )
VAR Actual = [Ingresos]
VAR Anterior = [Ingresos mes anterior]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ) || NOT UnMes, BLANK (),
        ISBLANK ( Anterior ),
            "Ingresos de " & MesActual & ": " & FORMAT ( Actual, "#,0" )
                & " · No hay mes anterior para comparar"
                & IF ( Anio = 2005 && Mes = 5, " (los datos empiezan el 24/05/2005)" ),
        "Ingresos de " & MesActual & " vs. " & MesAnterior & ": "
            & FORMAT ( Actual, "#,0" ) & " vs. " & FORMAT ( Anterior, "#,0" )
            & " · Meta ≥ +5 %"
            & IF ( Anio = 2005 && Mes = 6, " · mayo es un mes parcial" )
    )
```

Ejemplos (ambas tiendas):

| Mes | Subtítulo |
|---|---|
| mayo 2005 | Ingresos de mayo 2005: 4 823 · No hay mes anterior para comparar (los datos empiezan el 24/05/2005) |
| junio 2005 | Ingresos de junio 2005 vs. mayo 2005: 9 630 vs. 4 823 · Meta ≥ +5 % · mayo es un mes parcial |
| agosto 2005 | Ingresos de agosto 2005 vs. julio 2005: 23 092 vs. 29 347 · Meta ≥ +5 % |

La columna `dim_fecha[nombre_mes]` se ordena por `dim_fecha[mes]` (*Ordenar por columna*), así los meses salen en orden de calendario en el segmentador y en los gráficos.

**Título del gráfico mensual.** El gráfico de columnas y líneas de la página se filtra con el segmentador de tienda (y no con el de mes, para mostrar siempre los cuatro meses). Su título se arma con esta medida (*Formato → General → Título → Texto → fx → Valor del campo*), para que diga qué tienda se está viendo:

```dax
K1 Título gráfico =
VAR Tienda =
    IF (
        HASONEVALUE ( dim_tienda[store_id] ),
        "Tienda " & SELECTEDVALUE ( dim_tienda[store_id] ),
        "Ambas tiendas"
    )
RETURN
    "K1 · Ingresos y crecimiento mensual · " & Tienda
```

## K2 · Ticket promedio por alquiler

**Valor.** Formato: número, 2 decimales.

```dax
K2 Ticket promedio = DIVIDE ( [Ingresos], [Alquileres] )
```

Suma de `monto` ÷ suma de `cantidad`, como en la ficha. Incluye los alquileres con pago en cero. Es un promedio ponderado: el ticket de todo el período no es el promedio de los tickets mensuales.

**Meta.**

```dax
K2 Meta = 4.25
```

**Mes anterior y variación.** La variación se expresa en la misma moneda del ticket.

```dax
K2 Mes anterior =
IF (
    ISEMPTY ( fact_alquiler ),
    BLANK (),
    CALCULATE (
        [K2 Ticket promedio],
        PREVIOUSMONTH ( dim_fecha[fecha] ),
        REMOVEFILTERS ( dim_fecha )
    )
)

K2 Variación =
VAR Actual = [K2 Ticket promedio]
VAR Anterior = [K2 Mes anterior]
RETURN
    IF ( ISBLANK ( Actual ) || ISBLANK ( Anterior ), BLANK (), Actual - Anterior )
```

**Texto, estado y color.**

```dax
K2 Texto =
VAR Valor = [K2 Ticket promedio]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        ISBLANK ( Valor ), "Sin dato",
        FORMAT ( Valor, "#,0.00" )
    )

K2 Estado =
VAR Valor = [K2 Ticket promedio]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        ISBLANK ( Valor ), "Sin dato",
        Valor >= [K2 Meta], "Cumple la meta",
        "No cumple la meta"
    )

K2 Color =
VAR Valor = [K2 Ticket promedio]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        ISBLANK ( Valor ), "#737373",
        Valor >= [K2 Meta], "#5BD667",
        "#FF6B76"
    )

K2 Color variación =
VAR Variacion = [K2 Variación]
RETURN
    SWITCH (
        TRUE (),
        ISEMPTY ( fact_alquiler ), BLANK (),
        ISBLANK ( Variacion ), "#737373",
        Variacion > 0, "#5BD667",
        Variacion < 0, "#FF6B76",
        "#E6C84F"
    )
```

Los colores son los de `good`, `bad`, `neutral` y gris del tema `tema_invacom_elegido.json`, los mismos de K7 y K8.

## Casos especiales

| Caso | Qué muestra | Por qué |
|---|---|---|
| K1 de mayo de 2005 | «Sin dato» | No hay alquileres en abril de 2005 |
| K1 de junio de 2005 | Valor normal; `K1 Nota` avisa que mayo es parcial | Se compara con mayo, que es parcial (desde el 24/05/2005); el crecimiento sale inflado |
| K1 de febrero de 2017 | «Sin dato» | Enero de 2017 no tiene alquileres |
| K2 de febrero de 2017 | Valor normal, muy bajo | Es un solo día con 182 alquileres sin devolver (C06, C07) |
| Varios meses, un año completo o sin filtro de mes | K1 «Elige un mes» (gris) | K1 compara un mes contra el anterior; el segmentador de la página es de selección única. K2 sí da el ticket del período seleccionado |

## Comprobación contra SQL

`sql/08_validacion_k1_k2.sql` calcula los mismos valores por tienda y mes. Para comprobar:

1. Ejecutar el script en SSMS.
2. En Power BI, poner una tabla con `dim_tienda[store_id]`, `dim_fecha[anio]`, `dim_fecha[mes]`, `Ingresos`, `Ingresos mes anterior`, `K1 Crecimiento de ingresos %`, `Alquileres` y `K2 Ticket promedio`.
3. Los valores deben coincidir fila por fila.

También se puede revisar desde la **Vista de consultas DAX**:

```dax
EVALUATE
SUMMARIZECOLUMNS (
    dim_tienda[store_id],
    dim_fecha[anio],
    dim_fecha[mes],
    "Ingresos", [Ingresos],
    "Ingresos mes anterior", [Ingresos mes anterior],
    "K1", [K1 Crecimiento de ingresos %],
    "Alquileres", [Alquileres],
    "K2", [K2 Ticket promedio]
)
ORDER BY dim_tienda[store_id], dim_fecha[anio], dim_fecha[mes]
```

## Funciones DAX usadas

`SUM`, `DIVIDE`, `CALCULATE`, `HASONEVALUE`, `MAX`, `YEAR`, `PREVIOUSMONTH`, `REMOVEFILTERS`, `SELECTEDVALUE`, `ISBLANK`, `ISEMPTY`, `IF`, `SWITCH`, `FORMAT` y variables (`VAR … RETURN`). Sirven para la matriz de control de DWI-89.
